Provided data model

HAUZ Authentication ERD

Personal Account registration only. The Appwrite Auth user is shown to explain the identity link; it is managed by Appwrite and is not a HAUZ table.

Identity to account

account_access_grants connects the Appwrite Auth user to each HAUZ Account they may use.

Current access

current_access_grant_id identifies the one unrevoked grant currently allowed to provide access.

Personal Account

Each individual Account has one Personal Account profile and one Personal Role.
